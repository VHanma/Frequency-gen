# EtherShip Android

Android recreation of the Ether Ship / Magnetic Mind Generator concept.

## Engine
- 96 kHz preferred stereo PCM engine, 48 kHz fallback
- multi-oscillator sine synthesis
- per-oscillator AM and FM
- master low-frequency amplitude modulation
- 20-octave manual control from 0.04 Hz to about 41.9 kHz
- USB / wired / system audio output selection
- editable custom frequency bank
- presets for Ether Ship Core, Alien Communication, ESP / Telepathy, Telekinesis, Remote Viewing, Xenolinguistic Microtonal, Magnetic Mind Generator, Star Net ETI, Ultrasonic Contact, and 444 Calibration

## Historical-source boundary
Public Ether Ship descriptions document the Synthi AKS, Hammond organ, brain-wave analyzer, color control, 24-channel EQ, laser/crystal system, and a 20-octave control system. Publicly accessible descriptions do not publish a definitive Hz table mapping named psychic functions to exact settings, so those named presets are marked RECONSTRUCTION in the app and remain editable.
