# Install on Android

1. Download `MindForge-HypnosisOS-v2.0.0.apk` from the GitHub Actions artifact.
2. Open the APK on Android.
3. If Android asks, allow installs from the app you used to open the APK.
4. Install.

Package: `com.vhanma.mindforge`
Version: `2.0.0`

This v2 package replaces v1 because the application ID is intentionally unchanged. Saved WebView data may persist across upgrades depending on how the earlier build was installed.
