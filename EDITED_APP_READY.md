# Edited app package added

The clone has now been adapted into the complete UltraCarrier Android project package.

Included features:
- multiline text input and Android TTS synthesis;
- WAV, MP3, and FLAC file selection and PCM decoding;
- AM and DSB-SC ultrasonic carrier modulation;
- internal, USB-C DAC, wired, line, and HDMI route checks;
- dynamic carrier limit based on the active output route;
- low-latency AudioTrack streaming requests;
- live waveform display;
- visible maximum-media-volume control;
- complete Kotlin, Jetpack Compose, manifest, Gradle, unit-test, and APK-build workflow files.

The complete package is stored as `UltraCarrier_edited_project.zip.b64`. The repository ZIP download also contains this file. A normal ZIP package is being prepared separately because GitHub's text-file endpoint cannot directly create binary files.
